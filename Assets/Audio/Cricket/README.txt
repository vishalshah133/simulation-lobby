Cricket crowd clips. Drop royalty-free audio here, then run
  Simulation Lobby > Cricket > Fill Audio Kit
(or rebuild the scene). A clip is matched by its file name CONTAINING one of these:

  cheer_small   a ripple of approval            (threes)
  cheer_big     a proper cheer                  (fours, and a wicket falling)
  cheer_roar    the full stand                  (sixes)
  cheer_final   the roar when the match is won  (falls back to cheer_roar)
  groan         a collective "ooooh"            (dot balls, wickets)
  applause      steady clapping                 (twos, end of innings, result)
  applause_soft a polite clap                   (singles; falls back to applause)
  bat           leather on willow               (optional; procedural knock if empty)
  stumps        stumps going over               (optional; procedural knock if empty)

Aim for 1-4 seconds each, no music, no commentary, no distinct voices or whistles that are
recognisable. Check every clip's licence allows MONETISED YouTube use before publishing, and
keep the licence/attribution note next to the file.
